# Green Cabinet – Machine Safety Labeling

**Green Cabinet – Machine Safety Labeling** is an extension for LibreOffice Draw that provides a practical collection of safety pictograms, warning symbols, and labeling elements for marking machines, industrial equipment, and hazardous areas.

The extension integrates directly into LibreOffice Draw and adds a ready-to-use gallery of standardized safety symbols inspired by ISO safety labeling principles. It allows users to quickly create professional machine labels, warning stickers, and technical safety markings without the need for specialized graphic software.

---

## Features

### Safety pictogram gallery

The extension includes a clear and organized gallery containing:

- Warning symbols
- Prohibition signs
- Mandatory action icons
- Hazard pictograms
- Machine risk labels
- Technical marking elements

---

### Fully editable elements

All inserted objects can be customized directly inside LibreOffice Draw:

- Resize symbols
- Change colors
- Edit texts
- Combine multiple elements
- Create custom safety stickers
- Adapt layouts for print production

---

### Seamless LibreOffice integration

The extension works directly inside LibreOffice Draw and is designed for fast and intuitive use. Users can simply drag, insert, and modify safety symbols within their existing technical documentation.
